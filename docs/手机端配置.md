# 手机端配置（SmsForwarder）

电脑端起好之后（见根目录 README），手机这边只要做一件事：**收到短信就 POST 给电脑**。

推荐用开源的 [SmsForwarder](https://github.com/pppscn/SmsForwarder)（酷安也能搜到，或从该仓库 Releases 下 APK）。它支持 Webhook 通道，正好够用。

## 1. 拿到电脑的局域网地址

电脑上浏览器打开 `http://localhost:8788`，看「本机地址」那一格，形如 `192.168.1.23`。
（控制台启动时也会打印一行 `http://192.168.x.x:8788/sms`。）

## 2. 给 App 权限（国产 ROM 必做）

不做的话 App 会被系统杀掉，表现为「过一阵就收不到了」：

- 短信权限、通知权限
- 设置 → 应用管理 → SmsForwarder → **自启动 打开**、**省电策略 无限制**
- 最近任务卡片里**加锁**（下拉卡片点锁图标）

## 3. 新建转发规则

| 项目 | 填什么 |
|---|---|
| 规则名称 | 验证码到电脑 |
| 匹配方式 | 全部短信（或「内容包含 → 验证码」） |
| 发送通道 | **Webhook** |
| 请求地址 | `http://<电脑IP>:8788/sms` |
| 请求方法 | **POST** |
| 请求头 | `Content-Type: application/json` |
| 请求体 | `{"from":"{{FROM}}","content":"{{SMS}}"}` |

> 变量是**双花括号**。新版如果提示用别的变量名，照 App 里的提示填即可 —— 电脑端会把整个请求体扫一遍找数字，**只要带上 `{{SMS}}` 就行**，格式不挑。
> 实在不顺，请求体直接填 `{{SMS}}`（纯文本）也能跑。

## 4. 测试

1. 手机随便登录一个会发验证码的服务，或让朋友发条带 6 位数字的短信。
2. 电脑右下角应该弹提示，剪贴板里就是那个码。
3. 打不开电脑网页 → 服务没起来，先双击 `debug-run.cmd` 看报错。

## 连不上？按顺序排查

1. **电脑网页打不开** → 服务没启动。
2. **电脑网页能开，手机发不出去**
   - 双击 `allow-firewall.cmd`，放行 8788（要 UAC 确认）。
   - 确认两台设备在**同一网段**。很多公司/公共 WiFi 开了「客户端隔离」，手机根本连不到电脑。
   - 兜底方案：手机开 **USB 共享网络** 连电脑，电脑会多出一块网卡，地址一般是 `192.168.42.100`，把转发地址改成 `http://192.168.42.100:8788/sms`。
3. **收到了但识别成空** → 打开电脑网页看「最近收到的原始内容」，把内容贴出来，去调 `config.json` 的 `keywordPattern`。
4. **识别出了错的数字** → 同上，多半是短信里还有别的数字（金额、单号）得分更高。

## 换网络了怎么办

电脑换网（公司→家里）IP 会变，手机里的请求地址要跟着改。打开 `http://localhost:8788` 看「本机地址」一格，把新 IP 填回 App。

嫌麻烦的话，在路由器上给电脑绑一个固定 DHCP 地址。
